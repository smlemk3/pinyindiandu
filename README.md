# 拼音点读 · pinyindiandu

趣味汉语拼音四声练习网页：点选韵母，生成四声音标卡片，点击即可听标准发音。

在线仓库：[smlemk3/pinyindiandu](https://github.com/smlemk3/pinyindiandu)

## 这是什么

面向拼音启蒙 / 四声练习的静态网页工具。打开 `index.html` 即可使用，无需后端。

主要能力：

- **自选韵母**：输入如 `iuo`、`aoe`，或点选芯片、快捷分组（单韵母 / 复韵母 / 鼻韵母）
- **四声卡片**：每个韵母生成一声～四声，可随机打乱练习
- **点击发音**：优先播放本地 `audio/` 真人拼音音频；本地缺失时回退远程源
- **单层 ɑ**：展示使用拼音教材常见的单层 `ɑ`，而不是英文双层 `a`

当前收录小学常用韵母：单韵母、复韵母、前鼻韵母、后鼻韵母（共 24 个）。

## 怎么用

1. 用浏览器直接打开 `index.html`（或推送到任意静态托管后访问）
2. 在输入框填写要练的韵母，例如：
   - `iuo`
   - `a o e`
   - `ai,ei,ui`
3. 点击「生成卡片」或「打乱顺序」
4. 点击卡片听发音

`ü` 可输入 `v` 或 `ü`。

## 目录说明

```
├── index.html      # 练习页
└── audio/          # 本地拼音发音 mp3（优先使用）
    ├── a1.mp3
    ├── yi3.mp3
    └── …
```

音频文件命名为「音节 + 调号」，例如 `a1.mp3`、`wei2.mp3`、`ying4.mp3`。  
部分零声母韵母按普通话习惯映射到可发音节（如 `i→yi`、`u→wu`、`ü→yu`、`ui→wei`）。

## 技术说明

- 纯前端：HTML + Tailwind CDN + 原生 JavaScript
- 无需构建、无需服务器（本地双击或任意静态托管即可）
- 选择过的韵母会记在浏览器 `localStorage` 中
